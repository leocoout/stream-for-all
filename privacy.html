Política de Privacidade do Stream for All

Última atualização: 19 de agosto de 2026

O Stream for All não coleta dados do usuário. A extensão não envia dados para o desenvolvedor ou para terceiros. A extensão não tem servidores próprios, contas, anúncios ou ferramentas de análise.

Dados que ficam no seu dispositivo

A extensão guarda estes dados no armazenamento local do navegador:

  • Apelido: o nome que você escolhe.
  • Identidade criptográfica: um par de chaves gerado no seu dispositivo. A extensão usa as chaves para verificar os membros das salas.
  • Salas: a lista de salas que você criou ou entrou.

Esses dados não saem do seu dispositivo para o desenvolvedor. O navegador remove esses dados quando você desinstala a extensão.

Dados que a extensão transmite

  • Tela e áudio: a extensão envia a transmissão do seu dispositivo para os dispositivos dos membros da sala. A conexão é direta (WebRTC) e criptografada. A transmissão não passa por servidores de mídia. A extensão não grava a transmissão.
  • Apelido e presença: a extensão envia esses dados apenas para os membros da sala, pela mesma conexão direta.
  • Sinalização de conexão: a extensão troca mensagens criptografadas por relays públicos do protocolo Nostr para conectar os participantes. Os relays não podem ler essas mensagens. Os relays não têm acesso à transmissão.

Você inicia cada transmissão. A extensão envia a transmissão apenas para pessoas que o anfitrião aprovou. A transmissão termina quando você para de compartilhar.

Permissões

  • storage: guardar apelido, identidade e salas no seu dispositivo.
  • activeTab: identificar o servidor do Discord aberto para nomear a sala. A extensão não lê e não transmite o conteúdo da aba.
  • Comunicação com nossa página (leocoout.github.io/stream-for-all): a página de convite pode pedir à extensão para abrir uma sala. Nenhum outro site pode se comunicar com a extensão.

O que a extensão não faz

  • Não coleta informações pessoais, histórico de navegação ou atividade do usuário.
  • Não vende e não transfere dados para terceiros.
  • Não usa dados para publicidade ou análise de crédito.
  • Não usa dados para nenhum fim além do compartilhamento de tela entre amigos.
